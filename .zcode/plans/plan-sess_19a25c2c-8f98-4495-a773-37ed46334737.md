# 游戏角：4 个英语小游戏

## Context

研途阅读已有背词/填空/跟读等学习场景，缺一个轻量「玩中学」入口。新增**游戏角场景**（书架第 7 项 🎮 游戏 + 工作台文具盒按钮），内含 4 个游戏：🃏 词牌消消乐、🔤 拼词方块、⚡ 词力快答、🎯 字母救援。全部接入现有 22295 词词库（`ensureWordBank()` 懒加载），支持四/六/考研级别筛选（复用 `wordMatchesFilter`），记录个人最佳成绩（新键 `yt_games`）。UI 遵循现有书房视觉（复用 `sceneHead/seg/wCard/wBtns/qOpt` 原语），游戏动效新增 `gm*` 前缀 CSS。
