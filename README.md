# 研途阅读 · 考研英语阅读生成器

考研/四六级英语学习工具：无限随机生成真题风格的长阅读，配套阅读理解题、逐句对照翻译、背词、选词填空、录音跟读、错题本。纯前端单页应用，可离线使用（PWA）。

## 功能

- **阅读生成**：AI 联网生成（WorkBuddy 云端，免 Key）/ 本地模板引擎离线生成，二选一
- **四档难度**：四级 / 六级 / 考研标准 / 考研强化 — 词数、段数、词汇难度分别对齐官方考试大纲
- **阅读理解题**：每篇文章自动配套 5 道题（主旨大意/细节理解/推理判断/词义猜测），支持练习模式（即时判分）与考试模式（提交后统一出分+逐题详解），错题自动进错题本
- **图书翻页**：仿真 3D 翻页 / 长卷滚动双模式，滑动、方向键、按钮翻页，记住每篇阅读位置
- **点词查词**：阅读时点任意单词弹出释义，可一键加入背词
- **每日背词**：22295 词带级别标签，按 四级/六级/考研 筛选，不熟的词更早复现
- **15选10 选词填空**：四六级真题题型，三档难度
- **录音跟读**：逐句跟读 + 发音打分（需支持语音识别的浏览器）
- **长篇阅读 · 段落匹配**：四六级 Section B 真题题型（约 1000 词 + 10 题段落定位）
- **我的书房**：收藏、浏览历史、错题本、学习统计（连续打卡）、数据导出/导入备份
- **主题**：浅色书房 / 深色夜读 / 跟随系统

## 难度标准依据

容量与词汇难度按官方考试大纲校准：

| 考试 | 标准 | 出处 |
|---|---|---|
| 四级仔细阅读 | 300-350 词/篇 × 5 题 | [CET 考试大纲（中国教育考试网）](https://cet.neea.edu.cn/res/Home/1704/55b02330ac17274664f06d9d3db8249d.pdf) |
| 四级选词填空 | 200-250 词，10 空 | 同上 |
| 六级仔细阅读 | 400-450 词/篇 × 5 题 | 同上 |
| 六级选词填空 | 250-300 词，10 空 | 同上 |
| 考研英语一 Part A | 4 篇共约 1600 词（≈400 词/篇），生词≤3% | [研招网·考试内容与试卷结构](https://yz.chsi.com.cn/kyzx/en/201003/20100312/66045496.html) |

每篇文章生成后自动输出词汇分布报告（依据内置 22295 词级别标签词库）：阅读页元信息显示「四级内词汇 x% · 超纲 y%」，控制台有完整分布。

## 目录结构

```
index.html            页面外壳（书房案头架构）
assets/js/core.js     功能引擎（生成/做题/背词/填空/跟读/错题本，~190KB）
assets/js/book.js     翻页引擎 + 难度校验报告
assets/js/wordbank.js 词库（4.3MB，按需懒加载）
assets/css/app.css    视觉系统
lib/                  WorkBuddy 云端 SDK
sw.js                 PWA 离线缓存
manifest.json         PWA 清单
```

## 本地开发

```bash
python -m http.server 8766    # 在项目根目录起服务
# 打开 http://localhost:8766/index.html
```

改动 css/js 后运行 `node scripts/bump.mjs` 升级资源版本号（浏览器与 SW 才会拉新文件）。

## 推送后自动检查

push 到 GitHub 会触发 `.github/workflows/check.yml`：对 4 个 JS 文件做语法检查 + 页面结构 smoke 测试。

## 发布

在 WorkBuddy 客户端将本目录作为应用发布即可（生成对外链接）。APK 为 WebView 壳，加载的就是本站点。
